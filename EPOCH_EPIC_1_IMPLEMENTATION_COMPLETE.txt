================================================================================
KEY DESIGN DECISIONS
================================================================================

1. Snapshot-based cache invalidation
   - Leverages existing mechanism
   - Zero-cost automatic invalidation
   - No explicit cache clearing needed

2. Two-layer write barriers
   - Server level: protects UPDATE queries
   - Index level: defense-in-depth
   - Catches both API and programmatic mutations

3. Simple monotonic epoch ID
   - uint64_t counter sufficient
   - No clock dependency
   - Zero overhead

4. No durability across restarts (as specified in EPIC)
   - Epoch resets to INIT
   - New epochId assigned on next startup
   - Simplifies POC implementation
