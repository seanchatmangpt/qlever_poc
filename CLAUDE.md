QLever is a high-performance RDF graph database implementing SPARQL standards. C++20 mandatory. Handles billions of triples. Apache 2.0 licensed. Active development. GCC 11+, Clang 16+, CMake 3.27+, Ninja preferred. Dependencies: Boost 1.81, ANTLR 4.13.12, ICU 60+, OpenSSL 3.1.1, Zstandard 1.5.5, nlohmann/json 3.12.0, Google Test/Mock, S2 Geometry.

Engine (src/engine/) executes SPARQL via Operation strategy pattern. QueryExecutionTree composes operations. QueryPlanner cost-based optimization with join ordering and filter pushdown. IdTable memory-efficient results. ~30 operation types: IndexScan, Join, Filter, GroupBy, Limit, OrderBy. Index (src/index/) stores triples with CompressedRelation multiple permutations PSO POS OSP. Vocabulary maps IRIs/literals to IDs. TextIndex BM25 full-text. SpatialIndex S2 geometry. Pimpl pattern reduces dependencies. Parser (src/parser/) ANTLR-based converts SPARQL to ParsedQuery. Visitor pattern traverses parse trees. Supports property paths and materialized views. RDFTypes (src/rdfTypes/) core types Iri Literal Variable GeoPoint. Util (src/util/) 88 headers: AllocatorWithLimit CachingMemoryResource Synchronized<T> ConcurrentCache Cache HashSet BufferedVector Zstd FSST ConfigManager RuntimeParameters parallel sort chunked iteration streaming.
