# Tutorials — Learning Paths

Step-by-step guides to get you productive quickly. Start here if you're new to QLever Rust.

## Available Tutorials

### [Getting Started](./getting-started.md) ⭐ **Start here**

A 15-minute guide covering:
- Setting up QLever server (Docker)

3. **New to QLever?** → Start with [Getting Started](./getting-started.md)
