# BB80/20: Deterministic Receipts

Replace human consensus with guards: deterministic invariant checks, concrete benchmarks, event logs. Receipts (benchmark results + state hashes) are proof, not narratives. If work passes guards and benchmarks, it is correct; do not reiterate. Humans provide constraints; models validate deterministically.
