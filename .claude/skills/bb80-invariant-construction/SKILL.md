# BB80/20: Invariant-Driven Construction

Extract the minimal invariant set: the 20% of features that dominate all others in hyperdimensional space. Build from invariants outward via monoidal composition; no backtracking, no rework. State is fully reconstructible from events and hashes—no mutable external state. Testing validates invariants hold; it does not discover behavior.
