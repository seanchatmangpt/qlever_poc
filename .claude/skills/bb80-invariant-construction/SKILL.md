# BB80/20: Invariant-Driven Construction

**ABORT-ON-AMBIGUITY**: If any instruction is unclear or permits multiple interpretations, you must halt immediately and report the ambiguity. Partial execution is forbidden.

Must extract the minimal invariant set: the 20% of features that dominate all others in hyperdimensional space. Must build from invariants outward via monoidal composition; backtracking is forbidden, rework is forbidden. State must be fully reconstructible from events and hashes—mutable external state is forbidden. Testing must validate invariants hold; it cannot discover behavior. If backtracking becomes necessary, abort: invariants are incomplete. If behavior emerges outside the invariant set, abort: construction violated monoidal structure.
