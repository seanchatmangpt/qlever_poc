TEMPLATE: How to Reframe as Pure Existence Validator
================================================================================

BEFORE (Execution-oriented):
  validate_something() {
    do_work_1()
    check_result_1()
    do_work_2()
    check_result_2()
    report_combined_result()
  }

AFTER (Invariant-oriented):
  validate_something() {
    # Pure existence check: Does state satisfy invariants?
    test_invariant_1() || return 1
    test_invariant_2() || return 1
    # ... all invariants checked ...
    return 0  # All invariants hold
  }

KEY PRINCIPLE:
  - No mutations during validation
  - No side effects (no file writes except exit code)
  - Atomic result (all pass or fail, no partial states)
  - Deterministic and repeatable
  - Composable with other validators
